# 3 ЭТАЖА — редизайн сайта

Одностраничный сайт агентства недвижимости «3 Этажа» (Бузулук). Чистые HTML/CSS/JS, без сборки.

## Структура
- `index.html` — разметка
- `assets/css/style.css` — стили и адаптив (брейкпоинты 1180 / 980 / 760 px)
- `assets/js/main.js` — интерактив: слайдер, карусель, калькулятор ипотеки, квиз, модальные окна, формы
- `assets/img/` — изображения

## Заявки с форм
По умолчанию заявка открывается письмом на `info@3floors.ru`.
Чтобы заявки приходили автоматически, укажите адрес обработчика в `assets/js/main.js`:

```js
const FORM_ENDPOINT = 'https://formspree.io/f/XXXXXXX';
```

## Публикация
GitHub Pages → ветка `main`, папка `/ (root)`.
